# Graphics Series Codex

이 폴더는 엔진 독립적 그래픽스 연재를 예약 작업으로 한 편씩 작성하기 위한 저장소 로컬 지침을 담는다.

## 기준 문서

예약 작업은 다음 문서를 순서대로 읽는다.

1. `AGENTS.md`
2. `POST_STYLE_GUIDE.md`
3. `GRAPHICS_POST_GUIDE.md`
4. `GRAPHICS_SERIES_PLAN.md`
5. `_data/graphics_series.yml`
6. `scripts/graphics_series_codex/CODEX_AUTOMATION_PROMPT.md`

## 실행 단위

- 한 번의 예약 실행은 모든 앞 항목이 완료된 경우에만 다음 미작성 글 한 편의 초안을 만든다.
- 같은 `series_id`의 초안이 있으면 사용자 검토 중인 것으로 판단하고 아무 파일도 수정하지 않는다.
- 글마다 최소 한 개의 핵심 설명 이미지를 만든다.
- Jekyll 빌드와 이미지 경로 검증이 끝나도 초안은 계획표의 `[ ]` 상태를 유지한다.
- 사용자는 같은 초안에 수정을 반복해서 요청할 수 있으며, 이 과정은 수동 작업으로 처리한다.
- 사용자가 명시적으로 승인하고 완료 표시를 포함한 커밋과 푸시가 성공한 뒤에만 `[x]`가 유효하다.
- 미완료 글이 존재하거나 검증, 커밋, 푸시가 실패하면 다음 글을 시작하지 않는다.
- 예약 작업은 commit, push, 완료 표시와 외부 게시를 수행하지 않는다.

## 예약 활성화 전 결정할 사항

실제 예약을 만들 때는 다음 값을 정해야 한다.

- 실행 주기와 시각
- 실패한 실행만 알림을 받을지

예약은 검증 가능한 초안 작성까지만 담당한다. 사용자 승인과 완료 처리는 항상 수동 작업으로 진행하며,
승인된 변경의 commit과 push까지 성공해야 다음 예약 글을 작성할 수 있다.
